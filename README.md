# readme-research

這個 repo 收集〈README：一封寫給人工智慧的家書〉會用到的**歷史圖像**，記下每張圖的出處、授權狀態，以及用在作品的哪裡。

- 作品地圖：[readme-exhibition `00_PROJECT_MAP.md`](https://github.com/wufangci/readme-exhibition/blob/main/00_PROJECT_MAP.md)
- 作品本體（信與 skill）：[wufangci/README](https://github.com/wufangci/README)

## 從這裡開始

| 檔案 | 用途 |
|---|---|
| [`00_PRODUCTION_BOARD.md`](00_PRODUCTION_BOARD.md) | 圖像總表：編號、出處、授權、用途、檔案存放位置 |
| [`SESSION_HANDOFF.md`](SESSION_HANDOFF.md) | 交接：上次做到哪、下次從哪開始 |
| [`AGENTS.md`](AGENTS.md) | 給 AI 的常用記憶：規則、偏好、工作習慣 |

## 資料夾

| 資料夾 | 內容 |
|---|---|
| `01_images/` | 圖像原檔（**不進 git**，只留命名規則） |
| `02_rights/` | 出處與授權紀錄：館藏、申請、回覆 |
| `06_process/` | 研究歷程：決策紀錄、每次工作摘要 |

## 圖像不進 git

歷史圖像大多有著作權、館藏或肖像上的限制，這個 repo 只記錄**圖像在哪裡、能不能用**，不放原檔。原檔由作者自行保存，存放位置寫在總表裡。

家族照片不收進這個 repo。
