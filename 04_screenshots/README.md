# 04_screenshots — 資料截圖

> 第一輪候選（[`03_search/2026-10-23_round1_archive-org.md`](../03_search/2026-10-23_round1_archive-org.md)）每一項的重要頁面截圖：書名頁、插圖、圖版、地圖。
> **圖檔不進 git**（作者決定：圖像原檔不進 git，只備註來源）。這份 README 和 [`INDEX.md`](INDEX.md) 進 git，圖檔留在本機。

## 規則

- 一項資料一個資料夾：`<編號>_<簡稱>/`，編號和第一輪清單的 # 相同。
- 檔名：`<編號>_<簡稱>_n<頁序>.jpg`。`n<頁序>` 是 archive.org 書頁的頁序，原頁網址是 `https://archive.org/details/<identifier>/page/n<頁序>`。
  - 圖片條目（逐張上傳的 JPG）用 `_f<檔案序號>.jpg`。
  - 影片用 `_<影格秒數>.jpg`（archive.org 每 60 秒一張的縮圖，解析度低）。
- 截圖取自 archive.org 的書頁影像，是原掃描的完整頁面，沒有裁切或修改。
- 每張截圖的來源、頁面連結、權利欄位都列在 [`INDEX.md`](INDEX.md)。「原書圖說」欄只抄錄書上印的文字；圖像說明由作者撰寫。
- 要用進作品時，回到原頁面確認，並依 `02_rights/` 的授權紀錄處理。
